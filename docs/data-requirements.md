# DividendLab 数据需求清单

> 状态：初稿，基于 2026-08-08 的 akshare v1.18.83 实测（脚本见 git 历史 `spike/`）。
> 本文是字段级规格，回答「我们需要什么数据、从哪拿、怎么校验」。阈值类参数不在本文确定。

## 0. 总原则

1. **原始层与标准层分离**（AGENTS.md §5）。抓到的原始响应原样落盘，再解析成标准表。接口改版或字段变更时，已抓数据不受影响且可重新解析。
2. **每条记录带来源三元组**：`source`（接口名或 URL）、`fetched_at`（抓取时间）、`as_of`（数据自身的适用日期）。这是证据链的最小单位。
3. **两类数据，两种生命周期**：
   - ETF 自身数据（行情、分红、净值）→ **历史序列**，增量累积，一经落库视为不可变。
   - 指数成分权重 → **仅最新一期截面**，每次覆盖式更新，不建历史（见 AGENTS.md §4）。

## 1. ETF 候选池与基本信息

| 字段 | 类型 | 来源 | 必需 | 说明 |
|---|---|---|---|---|
| `etf_code` | str(6) | 交易所清单 | ✅ | 主键。6 位数字，保留前导零 |
| `etf_name` | str | `fund_etf_spot_em` | ✅ | 基金简称 |
| `index_code` | str | **人工维护** | ✅ | 跟踪指数代码。见 §1.1 |
| `index_name` | str | 人工维护 | ✅ | 用于人工核对 |
| `list_date` | date | 交易所 | ✅ | 上市日，决定历史起点 |
| `fund_company` | str | 东财/雪球 | ⬜ | |
| `status` | enum | 交易所 | ✅ | 正常/停牌/退市 |
| `share` / `market_cap` | float | `fund_etf_spot_em` | ⬜ | 规模代理，实时快照 |
| `mgmt_fee` / `custody_fee` | float | `fund_fee_em` | ⬜ | 逐只请求，易失效 |

**⚠️ `fund_etf_spot_em` 不能作为 ETF 全集**（约 937 只，已知缺 159985 等）。候选池清单应以交易所官网为准，akshare 只用于填充行情字段。

### 1.1 ETF→指数映射：本项目唯一的人工维护资产

akshare **没有**任何接口提供这个映射。特别注意 `fund_info_index_em` 有一列叫「跟踪标的」，但源码 `fund_em.py:368` 是 `temp_df["跟踪标的"] = symbol`——把入参原样回写，**不是真实映射**，不可使用。

红利类指数名称高度相似（中证红利 `000922` / 上证红利 `000015` / 深证红利 `399324` / 红利低波 `H30269`），文本模糊匹配必然出错。

**方案**：维护 `data/reference/etf_index_map.csv`，字段 `etf_code, index_code, index_name, source_url, verified_at`。来源优先级：基金合同/招募说明书 > 交易所基金列表的标的指数字段 > 中证官网「挂钩产品」反向列表。

**自动校验（必须实现）**：ETF 日收益对指数日收益回归，正确映射应满足 `R² > 0.98`、`beta ≈ 1`、年化跟踪误差 < 2%。映射错挂会被立即炸出。校验本身写入证据链。

## 2. 日行情（历史序列）

**接口**：`fund_etf_hist_em(symbol, period="daily", start_date, end_date, adjust="")`

| 字段 | 说明 |
|---|---|
| `trade_date` | 交易日 |
| `open/high/low/close` | **不复权** |
| `volume` / `amount` | 成交量 / 成交额 |
| `turnover_rate` | 换手率 |

**复权口径（重要）**：
- **落库存不复权**，总收益序列由「不复权价 + 分红明细」自行重构。
- 实测确认 `adjust="hfq"` 已正确处理分红（510880 除息日不复权 -4.97%，后复权 -0.37%）。**但不作为落库口径**——hfq 序列会随每次新分红整体漂移，昨天算的结果今天复现不出来，违反 AGENTS.md §13 可复现要求。
- hfq 可作为**校验用途**：自建总收益序列应与 hfq 序列高度一致，偏离即告警。

## 3. 分红（历史序列，本项目最关键的数据）

**接口**：`fund_fh_em(year=...)`

| 字段 | 说明 |
|---|---|
| `record_date` | 权益登记日 |
| `ex_date` | **除息日**——月月分红判定以此为准 |
| `pay_date` | 分红发放日 |
| `dividend_per_share` | 每份分红，**单位：元/份** |

### 3.1 三个必须遵守的实测结论

**① 必须按年遍历。** `fund_fh_em` 的 `year` 参数默认值硬编码 `"2025"`，无参调用只返回 2025 一年。同步时须显式遍历 `list_date` 年份至今。

**② 单位是元/份，不是每10份。** 已用价格跳空交叉验证：510880 声明 0.143，除息日实际跳空 0.139。落库时不做任何单位换算。

**③ 数据超前于当日，必须按除息日过滤。**
实测 2026-08-08 当天，接口已返回除息日 2026-08-14 的记录——东财收录**已公告但尚未除息**的未来分红。

> **这是本项目最容易引入前视偏差的地方。** 任何「已实现分红」的计算，必须先过滤 `ex_date <= 计算基准日`。回测中基准日为回测当日，而非今日。

反过来，这些未来记录本身是有价值的——可单独存为「已公告待除息」，用于前瞻提示，但**绝不可计入已实现口径**。

### 3.2 月月分红判定：三态

判定「最近连续 12 个完整自然月均有实际分红」时输出三态，而非布尔值：

- **合格**：过去 12 个完整月每月都有 `ex_date <= 基准日` 的记录。
- **不合格**：存在缺口月份，且该月已过去足够久（数据应已完整）。
- **待确认**：缺口出现在最近 1-2 个月，可能是公告未发布而非未分红 → 进入 AGENTS.md §3 的「证据不足/待核验」分支，不输出确定性结论。

### 3.3 缺口

`fund_fh_em` 无公告日期、无公告链接、无分红方案序号（**同月两次分红无法区分**）。证据链追溯需另接巨潮/交易所公告，或 `fund_announcement_dividend_em`（返回 art_code，需自行拼 URL）。

## 4. 净值（历史序列）

**接口**：`fund_etf_fund_info_em(fund, start_date, end_date)` → 净值日期、单位净值、累计净值、日增长率、申购/赎回状态。

⚠️ 内部每页 20 条循环分页，单只基金几十次请求，慢且易触发限频。建议低频全量、日常只增量拉最新交易日。

累计净值**不扣分红再投**，不能直接当总收益用。

## 5. 指数成分权重与行业（仅最新截面）

**接口**：`index_stock_cons_weight_csindex(symbol)`
实测 000922 返回 100 只、权重和 100.004、截面日期 2026-07-31。

| 字段 | 说明 |
|---|---|
| `index_code` / `index_name` | |
| `cons_code` | 成分券代码，用于 join 行业 |
| `weight` | 权重（%），合计 ≈100 |
| `as_of` | **权重截面日期，所有输出必须标注** |

**行业分类**：中证成分表**无行业列**，需 join `stock_industry_clf_hist_sw`（申万，含计入日期）。国证系（`index_detail_hist_cni`）自带「所属行业」列但为国证口径。跨指数横比须统一，**建议统一用申万一级**。

**待验证捷径**：中证官网指数详情页/月报可能直接公布行业权重分布。若可爬则免去 join、且是官方口径，证据链更硬。用 playwright 验证。

**用途边界**：行业权重指标**只用于当期筛选，不得进入回测**（AGENTS.md §4/§6）。

## 6. 工程约束

**东财不稳定是常态，不是异常。** 本地 spike 中 `fund_etf_hist_em("515080")` 连续重试 4 次全部 ProxyError 失败。

必须实现：
- 重试 + 指数退避；请求间隔 sleep 3-5s + 随机抖动。
- 熔断：连续失败 N 次停止任务，避免被封 IP。
- **单只 ETF 失败不得拖垮全量任务**，失败项记入 warnings 并在结果中明示。
- 每个接口写 schema 断言，字段变更立即告警而非静默出错。

**合规**：akshare 声明数据仅供学术研究、不可商用，数据版权归上游（东财、中证指数公司）。落库数据不对外分发。
